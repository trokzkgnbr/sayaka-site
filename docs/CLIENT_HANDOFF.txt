3. お名前.com での維持
================================================================================

  お名前.com は「ドメイン（sayayosui.site という住所）」の管理をしています。

  【毎年必要な作業】
    ドメインの更新（更新料の支払い）

  【更新料の目安】
    年 3,000 〜 5,000 円前後
    ※ .site ドメインの場合。キャンペーンや更新時期により変動します。

  【更新を忘れた場合】
    ドメインが失効し、サイトにアクセスできなくなる可能性があります。
    カレンダー等で更新時期をメモしておくことをおすすめします。

  【補足】
    サイトの表示そのものは GitHub Pages が担当しています。
    ドメインの向き先（DNS）は Cloudflare 経由に設定済みです。
    お名前.com では主に「ドメインの更新・支払い」を行うイメージです。

4. Blog（日記）の更新方法
================================================================================

  スマホだけで更新できます。

  【管理画面 URL】（公開サイトにはリンクを載せていません）
    https://sayayosui.site/blog-mgt-bf8fa662/

    → ブックマークしておいてください。

  【手順】
    1. 上記 URL を開く
    2. パスワードでログイン
    3. 「投稿を登録」または「投稿を削除」
    4. 数分以内に本番 Blog へ反映
       （または 1 日 2 回：9:00 / 21:00 の自動チェックで反映）

  【投稿の書き方】
    ・画像を 1 枚選ぶ（JPEG / PNG / WebP。大きな写真は自動で軽くします）
    ・日付を指定（空欄なら当日）
    ・本文の 1 行目が Blog のタイトルになります
    ・2 行目以降が本文として表示されます

  【Blog 更新に追加料金はかかりません】
    投稿・削除の回数に上限料金はありません（無料サービスの範囲内）。

4.5 Blog 画像の保存上限について
================================================================================

  GitHub には「何枚まで」という枚数の上限はありません。
  ファイルが何千枚になっても、枚数そのもので突然停止することはありません。

  実際の上限は「容量」です。

    ・公開サイト全体（GitHub Pages）… 目安 1 GB
    ・1枚あたり（自動縮小後）… およそ 200〜400 KB
    ・この場合、単純計算で 2,000 枚以上は余裕があります

  月に数回の投稿であれば、数年〜十年単位で問題になりません。
  1か月で容量がいっぱいになって使えなくなる、ということはありません。

  【1か月後に止まる可能性があるもの】
    ・Blog を GitHub に書き込むための接続キー（トークン）の期限
      ※ 作成時の設定が 30 日だと、期限後は投稿できなくなります
      ※ サイトの閲覧は続きます。投稿・削除だけができなくなります
      ※ 期限切れのときは管理画面に案内が出ます。寺尾までご連絡ください
    ・お名前.com のドメイン更新忘れ（年1回。サイト全体が開かなくなります）

  【長く使うための仕組み】
    ・投稿時に画像を自動で軽量化します（スマホの原版のまま保存しません）
    ・削除した投稿の画像は公開フォルダから除きます

5. Blog 以外の更新（Gallery・固定ページなど）
================================================================================

  トップページ、About、Gallery の画像差し替えなどは、Blog 管理画面では
  変更できません。GitHub 上のファイル変更が必要なため、制作者または
  寺尾への依頼が必要です。

  内容によって作業費（技術サポート料）が発生する場合があります。
  サービス利用料（月額・従量）とは別です。

6. 運用コストの目安
================================================================================

  【ほぼ確実にかかるもの】
    ・お名前.com のドメイン更新料 … 年 3,000 〜 5,000 円前後

  【月平均に換算】
    約 250 〜 450 円 / 月（ドメイン更新を 12 ヶ月で割った目安）

  【通常の運用でかからないもの】
    ・Blog の投稿・削除（回数無制限）
    ・Cloudflare 無料プラン
    ・GitHub / GitHub Pages（公開リポジトリの場合）
    ・一般的なアクセス数でのサイト閲覧

  【条件が変わると追加料金の可能性があるもの】
    ・GitHub を非公開リポジトリに変更した場合 … GitHub 有料プラン
    ・Cloudflare / GitHub の無料上限を大幅に超える場合 … 個人サイトでは稀
    ・お名前.com でレンタルサーバー・メール等を追加契約した場合
    ・デザイン変更・ギャラリー大量追加など … AI費,サーバーコスト費

7. 困ったとき
================================================================================

  症状                          考えられる原因
  --------------------------------------------------------------------------
  サイト全体が開かない          ドメイン更新忘れ、DNS、GitHub 障害
  Blog だけ古い内容のまま       反映待ち（数分）、ブラウザのキャッシュ
  管理画面にログインできない    パスワード誤り、初期設定未完了
  投稿・削除ができない          GitHub 連携の期限切れ、または初期設定の不具合

  管理画面には「困ったら寺尾まで」と表示されています。
  上記で解決しない場合は、寺尾までご連絡ください。


================================================================================
8. ブラウザで表示が古いとき
================================================================================

  レイアウトや Blog の表示が更新されない場合、ブラウザのキャッシュが
  原因のことがあります。

  【再読み込みの方法】
    Mac     … Command + Shift + R
    Windows … Ctrl + Shift + R

  スマホの場合は、タブを閉じて URL から開き直してください。
